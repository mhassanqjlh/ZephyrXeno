## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ZephyrXeno.git`
2. `cd ZephyrXeno`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ZephyrXeno, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
